## Per-topic deliverables (every new page)

Every new topic gets the existing UK Test Hub treatment, matching the current pattern in `src/routes/topic.$slug.tsx`, `src/routes/guide.$slug.tsx`, and `src/routes/quiz.$slug.tsx`:

1. Entry in `src/data/categories.ts` under the correct category (no removals)
2. Entry in `scripts/topic-requirements.json` (45 mocks × 24 questions, type weights tuned per topic) + `src/data/mocks/mock-index.json`
3. `public/mocks/{slug}.json` — full v2 bank generated by the existing `scripts/generate_mocks.py` pipeline via Lovable AI Gateway (`google/gemini-3-flash-preview`), 1080 questions, 4 options each, 1 correct, short explanation
4. SEO entry in `src/data/topic-seo.ts` — unique title (`[Topic] Practice Test | UK Test Hub`, ≤60 chars) and description (≤160 chars, your template wording)
5. Topic page + study guide page render automatically from the existing route handlers — including breadcrumb schema, FAQ schema, self-canonical, og:url, `IndependentDisclaimer`, related-tests block, "Start Practising" CTA. Independent-disclaimer wording will be widened to mention the additional bodies you listed (CompTIA, AWS, Microsoft, Cisco, AAT, ACCA, CIMA, NEBOSH, IOSH, RTITB, ITSSAR, etc.)
6. `src/data/slug-redirects.ts` — 301s for `gre-practice-test → gre-practice` and `gmat-practice-test → gmat-practice`
7. `src/routes/sitemap[.]xml.ts` — automatic. New categories/topics/quizzes/English mocks are derived from `categories`, `mock-index.json` and `allEnglishLevelTriples()`, so adding them to source data adds them to the sitemap with no further code

## Generation pipeline

For each of the 16 topic banks, run:
```
python scripts/generate_mocks.py bank     --topic {slug}
python scripts/generate_mocks.py assemble --topic {slug}
python scripts/generate_mocks.py validate --topic {slug}
```
For the 2 new English tests, use `scripts/generate_all_english_mocks.py` (same script that produced the existing IELTS/TOEFL/SELT banks).

Quality guardrails baked into prompts (matches your rules):
- Question stems must start with a capital letter and **must not** contain the topic title or "practice question N:" prefix (the recent QuizRunner fix you shipped)
- "Practice-style", "mock test", "revision" wording only — no "official", "guaranteed pass", "real exam questions"
- 4 options, 1 correct, ≤2-sentence explanation grounded in current UK guidance for the relevant body (DVSA / DfT / NHS / CITB / CompTIA / Microsoft / AWS / Pearson / Duolingo)

## Estimated cost & runtime

Each topic bank ≈ 1,080 questions ≈ 90 Lovable AI calls (12 questions/batch). 16 topic banks + 48 English banks ≈ **5,760 Lovable AI requests**. At Gemini 3 Flash Preview rates this is a meaningful credit spend and will take roughly 60–120 minutes of script time. The pipeline is resumable, so partial failures don't lose progress.
